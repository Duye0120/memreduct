# 0.0.7

## Bug fixes

- Fix in-app updates being blocked when the app is installed on D: or in another user-writable folder.
- Install updates through the protected helper, preserving the selected installation folder and existing settings.
- Reopen the app once with ordinary permissions after completing or canceling the update installer.

## Installation

Versions 0.0.6 and earlier retain the old update restriction. If installed in a user-writable folder, download and run this installer once. Later updates can use the in-app updater. Administrator approval is requested only when installing an update.

# 0.0.7 中文更新日志

## 错误修复

- 修复程序安装在 D 盘等普通用户可写目录时，无法在应用内更新的问题。
- 更新安装改由受保护助手执行，保留已选安装目录和现有设置。
- 完成或取消更新安装后，以普通权限重新打开一次程序。

## 安装说明

0.0.6 及更早版本仍包含旧的更新限制。如果安装在普通用户可写目录，请手动运行本次安装包一次；后续可使用应用内更新。更新仅在安装时请求管理员授权。
