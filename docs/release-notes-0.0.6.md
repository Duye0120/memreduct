# 0.0.6

## Features

- Animate memory values and progress bars during cleanup, then return to the latest readings.

## Improvements

- Keep recent cleanup history collapsed by default. New records no longer expand the list automatically.
- Remove the redundant live indicator during normal monitoring while keeping read-error alerts.
- Show memory pressure as colored text without a button-like background or border.

## Installation

Upgrading preserves your settings. In-app installation requires a protected app folder. If the app is installed in a user-writable folder such as `D:\apps`, download and run the installer from this release.

# 0.0.6 中文更新日志

## 功能

- 清理时为内存数字和进度条添加动画，完成后恢复到最新读数。

## 改进

- 最近清理默认收起，新增记录不会自动展开列表。
- 正常监测时移除多余的实时标识，保留读取异常提示。
- 内存压力改为彩色文字显示，移除类似按钮的背景和边框。

## 安装说明

升级保留你的设置。应用内安装更新要求程序目录受管理员保护；如果安装在 `D:\apps` 等普通用户可写目录，请从本页下载安装包后运行。
