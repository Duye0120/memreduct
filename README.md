# memreduct-winui

面向 Windows 的内存监测与清理工具，采用 C# 与 WinUI 3 构建，提供实时内存概览、数字托盘、自动清理和全屏保护。

项目处于持续完善阶段，当前正式版本见 [Releases](https://github.com/Duye0120/memreduct-winui/releases/latest)。

本项目基于 **Henry++** 开发的 **[Mem Reduct](https://github.com/henrypp/memreduct)** 改造，是独立维护的衍生版本。感谢原作者及上游贡献者提供的开源基础；本项目与原版分别维护和发布。

## 功能

- **实时监测**：展示物理内存、已提交内存与系统文件缓存，每秒更新。
- **内存趋势**：查看最近 5 分钟的物理内存和已提交内存变化；采样记录仅保存在当前进程中。
- **清理记录**：保留本次运行最近五次清理的结果、耗时和错误状态，区分手动与自动清理。
- **进程概览**：按需查看工作集占用最高的八个进程，支持手动刷新，不在后台持续扫描。
- **内存清理**：提供八项可选清理操作，每项附有说明，支持手动清理与按用量、时间间隔自动清理。
- **数字托盘**：显示内存使用率，通过颜色提示用量与清理结果；清理时显示旋转动画，可选成功通知。
- **全屏保护**：检测前台全屏应用并暂停自动清理，离开全屏后恢复计划。
- **统一界面**：支持浅色、深色、跟随系统主题，以及顶部导航和侧栏布局。
- **语言支持**：简体中文、English 和跟随系统；切换语言后可选择立即或稍后重启应用。
- **启动与更新**：安装版支持授权后的管理员登录自启，并从本仓库检查和下载安装更新。

## 系统要求

- Windows 10 版本 2004（内部版本 19041）或更高版本，x64 架构。
- 安装包包含所需的 .NET 与 Windows App SDK 运行依赖。
- 内存监测可使用普通权限；内存清理需要管理员权限。

## 安装与使用

安装包通过本仓库的 [Releases](https://github.com/Duye0120/memreduct-winui/releases) 页面分发，文件名为 `MemReductFluent-X.Y.Z-win-x64-setup.exe`。

1. 运行安装程序，选择安装目录并按向导完成安装。默认目录为 `Program Files\MemReduct Fluent`，首次安装可选择其他本地目录并导入本项目便携版的 `settings.json`。
2. 打开应用，在“内存”页面查看用量或执行清理。
3. 在“设置”中选择清理区域、自动清理条件、主题和语言。
4. 如需登录后自动清理，在安装版中开启“开机启动”，使用当前登录的管理员账户完成授权。

关闭窗口默认收起到托盘。首次左键点击托盘数字时，会说明清理操作，并让你选择以后是否需要确认。右键菜单中的“手动清理前确认”以勾选标识当前状态，可直接切换，与设置页同步；菜单还可打开主窗口、切换游戏模式或退出。

清理确认与 Windows 管理员授权相互独立。程序以管理员权限运行后，本次运行无需反复授权；安装目录受管理员保护时，开启“开机启动”并完成授权后，之后登录或手动重新打开程序会复用授权的启动任务。

带 `*` 的“已修改页面列表”和“全部备用列表”仅用于手动清理，不参与自动清理。全屏保护也适用于全屏视频等应用。

## 更新与设置

在 **设置 → 关于 → 检查更新** 中检查新版本。安装版读取本仓库的正式 `fluent-vX.Y.Z` Release，经用户确认后在后台下载并显示进度，期间可以继续使用程序或取消下载。下载完成后点击 **安装更新**，授权并验证安装包后打开安装向导，安装成功后自动重新打开程序；取消授权可稍后重试。便携版提供发布页入口。

更新源为 [Duye0120/memreduct-winui](https://github.com/Duye0120/memreduct-winui/releases)。仅推送源码不会产生应用更新，需要发布对应版本的安装包。

升级会沿用已安装目录。需要迁移目录时，请先卸载再安装到新目录，个人设置会保留。若选择普通用户可写的目录，管理员自启和应用内安装更新不可用；可从 Releases 手动下载安装包升级。

| 版本 | 设置位置 |
| --- | --- |
| 安装版 | `%LOCALAPPDATA%\MemReductFluent\settings.json` |
| 便携版 | 程序 EXE 同目录下的 `settings.json` |

升级与卸载保留个人设置。导入便携版设置只复制原文件，不覆盖已有安装版设置；Henry++ 原版的 INI 文件与启动任务保持独立。
